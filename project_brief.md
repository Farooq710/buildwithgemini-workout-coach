# My agent: Ronny — AI Workout Coach

One-liner: An agent-first personal fitness coach with A2UI cards, Google Cloud Firestore persistence, biomechanical safety rails, and Google Maps facility scouting.

## Overview
Ronny is an intelligent workout coach and training partner built using an agent-first architecture. It combines deterministic biomechanical safety rules and progressive overload calculations with Gemini LLM reasoning, Vertex AI/Google Cloud Firestore state persistence, rich interactive A2UI cards, and Google Maps Platform integration for local gym and track scouting.

## Capabilities & Architecture
- **Agent Intelligence**: Multi-tool agent orchestrated with ADK patterns and biomechanical rules.
- **Biomechanical Safety Engine**: Enforces strict contraindication checks (e.g., lower back, shoulder, knee pain) and red-flag symptom triage.
- **Long-Term Memory & State**: Full profile, workout plan, and session set logging stored in Google Cloud Firestore.
- **Rich A2UI Protocol (v0.8)**: Generates native card components (Cards, Columns, Rows, Dividers, Texts) for interactive plans and scouted facilities.
- **Google Maps Integration**: Scouts gyms, barbell clubs, and outdoor running tracks with one-click directions and embedded map previews.
